# ColorAVI

Libro de colorear para niños: sube tus propios dibujos o fotos y píntalos con relleno, crayón, plumón, brillantina y rodillo de figuras.

- Funciona sin internet una vez instalada (app web / PWA).
- Los dibujos se guardan solo en el dispositivo; nada se sube a ningún servidor.

## Instalar en el iPad

1. Abre la dirección de GitHub Pages en **Safari**.
2. Toca **Compartir → Añadir a pantalla de inicio**.
3. Abre ColorAVI desde el ícono; desde ahí funciona sin conexión.
